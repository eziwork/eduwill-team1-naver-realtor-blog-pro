# 공인중개사 AX 원데이클래스 — 매물 블로그 실습

매물의 조건을 고객의 검색 질문과 연결하고, 상담으로 이어지는 글 한 편을 만듭니다.

1. 내 매물번호/링크 또는 매물 설명과 사진을 전달합니다.
2. AI가 확인된 매물 정보와 미확인 사항을 나누고, 타겟·검색 의도·글 전략 한 안을 추천합니다.
3. 타겟과 강조할 내용을 확인하거나 수정합니다. 확정 전에는 최종 원고를 쓰지 않습니다.
4. 저장 문체가 없으면 내 블로그 주소를 전달합니다. 공개 매물 글 최대 5개로 말투를 분석합니다. 자료가 없으면 기본 문체를 사용합니다.
5. 썸네일·사진·조건표·지도·상담 배너를 포함한 글을 제작합니다.
6. Codex 내장 브라우저에서 네이버에 직접 로그인합니다.
7. 임시저장한 같은 글을 다시 열어 제목·본문·사진·표·지도·연락처를 검수합니다.
8. 공개 발행은 수강생이 최종 확인 후 직접 합니다.

요청 예시:
> $naver-realtor-blog-pro 이 매물의 고객과 검색 의도에 맞는 전략을 추천해줘. 확정하면 내 문체로 글을 만들어 임시저장·검수해줘.

검색어는 실시간 검색량을 조사한 결과가 아닌 추천 후보입니다. 상위 노출을 보장하지 않습니다.
모르는 가격·면적·거리·시설·이용 조건을 만들지 않으며 질문을 한 번에 모읍니다.
전화 상담은 '문의 주세요'로 끝내지 않고 상담에서 확인/안내할 내용을 설명합니다.

설치: Node.js 20 이상. 매물번호 수집을 쓰면 스킬 폴더에서 npm ci.
기존 스킬 호출명과 사무소 프로필은 유지됩니다. 공개 발행·다른 채널 콘텐츠 제작은 이번 실습에 포함되지 않습니다.
