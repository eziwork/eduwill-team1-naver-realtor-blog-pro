# 구현 검증 기록

## v0.3 현장 포인트·상담 노하우

검증일: 2026-10-09. 기존 24개와 신규 15개를 포함해 자동 테스트 39개 통과.
설치본의 최신 친숙한 존댓말·한 문장씩·가운데 정렬·문장 사이 빈 줄·고객용 글에 수집 상태를 노출하지 않는 규칙을 먼저 반영했습니다.

- 필요한 현장 질문 최대 2개·한 묶음, 충분한 입력에서 질문 생략, 답변/건너뛰기/미응답 처리
- 확인된 사용자 사실 연결과 중개사 평가·개별 고객 반응의 분리
- 사용자 반복 경험만 저장, AI/개별 경험 분류 및 연락처가 포함된 저장·수정·충돌·잊기 입력 거부
- 유형·거래·확인된 지역의 정확한 범위 조회, 무관한 아파트·다른 지역 제외
- 중복 방지, 명시적 대체, 모호한 충돌 보류와 전체 해결, 비활성화와 자동 부활 방지
- 전략 참조 스냅샷 검증, 새 기억 저장 후 기존 확정 유지
- 동일 매물 사실에 서로 다른 현장 포인트를 붙인 타겟·후킹·설명 순서 예시 비교
- 두 작업 연속 실행: 첫 창고의 상담 우선순위가 다음 전략에 반영되며 200㎡/6m/5톤은 두 번째 80㎡/3m/1톤 원고에 섞이지 않음
- 기존 YAML·블로그 문체 바이트 보존, 사무소 폴더 간 분리, 선택 필드 없는 기존 작업 호환, CLI 전 과정
- 가운데 정렬과 빈 문단을 포함한 로컬 HTML 보존

기억 테스트는 임시 사무소 폴더에서 실행하며 실제 사무소 프로필·기억에 예시를 저장하지 않습니다.
자연어 의미 판단은 Codex의 책임입니다. 유형별 전략 fixture는 AI가 모든 입력에 올바르게 추론한다는 증명이 아닙니다. 개인정보 패턴 검사는 이름 익명화나 의미상 중복 판단을 대신하지 않습니다.
이번 변경은 전략 전 현장 질문과 상담 노하우 저장·조회입니다. 네이버 입력·임시저장 절차는 유지했으며 브라우저 실검증은 아래 v0.2 기록을 계승합니다. 이번 버전에서 실제 네이버 글을 추가 저장하지 않았습니다.

검증일: 2026-10-09 (Asia/Seoul). 작업 시작일은 10월 8일입니다.

## v0.2 실제 내장 브라우저 검증

사용자가 지정한 michael3014 블로그에서 테스트용 글 한 편을 임시저장했습니다.
제목: [호환성 테스트·미발행] AX 매물 블로그 내장 브라우저 검수 20261008
저장 목록 시각: 2026.10.09 00:05. 기존 2개에서 3개로 증가했습니다.
공개 발행하지 않았으며 기존 두 임시저장 글을 수정하지 않았습니다.

- 사용자 수동 로그인 후 글쓰기 진입
- 제목 입력, 본문 HTML 일괄 붙여넣기
- 실제 2열 3행 표의 모든 셀 유지
- filechooser로 테스트 PNG 업로드
- 서울특별시청 검색→주소 확인→추가→확인으로 실제 지도 컴포넌트 삽입
- 테스트용 전화 문자열 000-0000-0000과 tel:00000000000 링크 확인(실제 연락처 아님)
- 저장 후 **새 탭에서 임시저장 목록을 열어 동일 제목·저장 시각의 글 재열람**
- 사진 640px 원본 로드, 지도 1400px 썸네일 로드, 본문 전체/표/연락처 링크 유지 확인

편집기 링크는 a[href] 외에 span.se-link[data-href]에도 존재합니다.
일반 a 태그 개수만 확인하는 방식은 링크 누락을 오판하므로 전송 계약에 두 형식을 명시했습니다.
현재 편집 중인 글을 목록에서 다시 클릭하면 '현재 편집중인 문서입니다'로 끝나므로, 재열람 시험은 새 탭에서 수행했습니다.

로컬 증거: 저장소 outputs/browser-smoke/의 source.html, title.txt, test-image.png, draft-list.txt, reopened-evidence.json, reopened.png.
이 경로는 계정별 실행 결과라 Git에서 제외됩니다. 네이버 임시저장본은 해당 계정에서 확인합니다.

## 자동 검증 범위와 한계

테스트는 유형별 구조화 데이터→전략→원고 렌더링, 확정 게이트, 조건/타겟 변경, 문체 저장/재사용/자료 부족, 출처·수치·단위·배너·이미지 검사, 실패 후 원고 보존, 중복 방지, 재열람 완성도 판정을 검증합니다.

로그인 만료·업로드 실패·저장 확인 실패는 **상태 전이 모의 테스트**입니다. 실제 계정을 강제 로그아웃하거나 실제 네트워크 장애를 유발하지 않았습니다.
유형별 fixture 결과는 기대하는 전략 차이를 검증하는 데이터이며 AI 추론 정확도나 실제 검색 성과의 측정치는 아닙니다.
매물번호 수집기와 이전 Playwright 전송기는 이번에 동작을 바꾸지 않았으며 실제 매물 수집/이전 전송기 재실행은 검증 범위 밖입니다.
실제 매물 광고의 의미 검수와 실제 사무소 배너 제작은 개별 매물 실행 때 이루어집니다.
